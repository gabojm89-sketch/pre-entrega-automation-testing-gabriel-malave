# Pre-Entrega: Automatización de Pruebas QA

Proyecto de automatización de pruebas end-to-end sobre la plataforma **SauceDemo** utilizando Python, Selenium WebDriver y Pytest.

## Tecnologías Utilizadas
* Python 3.x
* Pytest
* Selenium WebDriver
* Pytest-HTML (Reportes)

## Instalación de Dependencias
Asegúrate de tener un entorno virtual activo y ejecuta:
```bash
pip install -r requirements.txt
